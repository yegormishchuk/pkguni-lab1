## 1. Цель работы

Изучить цветовые модели RGB, XYZ и CIE LAB и алгоритмы перехода между ними. Разработать интерактивное приложение, отображающее цвет одновременно в трёх моделях с возможностью редактирования из любой из них.

---

## 2. Задача и реализованные требования

- Задание цвета несколькими способами: ползунки, числовые поля, графическая палитра (выбор цвета).
- Автоматический пересчёт всех моделей при изменении любой компоненты.
- Все преобразования реализованы вручную по формулам, без сторонних библиотек конвертации цвета.
- Гамма-коррекция sRGB при переходе между нелинейным и линейным RGB.
- Опорный белый — стандартный источник D65.
- Обработка выхода за цветовой охват sRGB (Clipping) при переходе XYZ/LAB → RGB.
- Ненавязчивое предупреждение, если значения RGB были обрезаны.
- Предпросмотр текущего цвета с отображением HEX-кода.

## 4. Ход работы

### 4.1 Структура проекта

- **`converter.js`** — математика преобразований: RGB ↔ XYZ, XYZ ↔ LAB, обращение матрицы 3×3. Не зависит от DOM.
- **`app.js`** — интерфейс: генерация карточек моделей, синхронизация ползунков и полей ввода, пересчёт при изменении, предпросмотр и предупреждение.
- **`index.html`, `style.css`** — разметка и стили (адаптивная вёрстка, светлая и тёмная темы).

### 4.2 Реализованные преобразования

**RGB → XYZ**  
Компоненты нормируются в [0, 1], затем линеаризуются (обратная гамма sRGB):

```
C_lin = C ≤ 0.04045 ? C / 12.92 : ((C + 0.055) / 1.055)^2.4
```

Далее применяется матрица sRGB (D65):

```
| X |   | 0.4124564  0.3575761  0.1804375 |   | R_lin |
| Y | = | 0.2126729  0.7151522  0.0721750 | · | G_lin |
| Z |   | 0.0193339  0.1191920  0.9503041 |   | B_lin |
```

**XYZ → RGB**  
Используется обратная матрица, вычисленная программно (через алгебраические дополнения в JS, `np.linalg.inv` в Python). Затем прямая гамма-коррекция:

```
C = C_lin ≤ 0.0031308 ? 12.92 · C_lin : 1.055 · C_lin^(1/2.4) − 0.055
```

**XYZ ↔ LAB**  
Формулы CIE 1976, опорный белый D65: Xn = 0.95047, Yn = 1.0, Zn = 1.08883.

```
f(t) = t > 0.008856 ? cbrt(t) : 7.787·t + 16/116
L = 116·f(Y/Yn) − 16
a = 500·(f(X/Xn) − f(Y/Yn))
b = 200·(f(Y/Yn) − f(Z/Zn))
```

Обратное преобразование:

```
fy = (L + 16) / 116,  fx = fy + a/500,  fz = fy − b/200
f⁻¹(t) = t > 0.008856 ? t³ : (t − 16/116) / 7.787
X = Xn·f⁻¹(fx),  Y = Yn·f⁻¹(fy),  Z = Zn·f⁻¹(fz)
```

**RGB ↔ LAB**  
Выполняется через промежуточную модель XYZ.

### 4.3 Обработка выхода за цветовой охват

Не каждая комбинация XYZ/LAB представима в sRGB. Если после преобразования хотя бы одна компонента выходит за [0, 1], применяется **Clipping**:

```
v' = clamp(v, 0, 1)
```

При этом в интерфейсе показывается предупреждение: *«Внимание: значения RGB были обрезаны (выход за пределы допустимого диапазона)»*.

### 4.4 Интерфейс

Для каждой модели (RGB, XYZ, LAB) каждая компонента задаётся:
1. **Ползунком** — R, G, B ∈ [0, 255]; X, Y, Z ∈ [0, 1.2]; L ∈ [0, 100], a, b ∈ [−128, 128].
2. **Числовым полем** для точного ввода (синхронизировано с ползунком).

Дополнительно цвет можно выбрать из **графической палитры** (нативный `<input type="color">` в веб-версии, `QColorDialog` в PyQt5). Над панелями отображается образец цвета и его HEX-код.

Защита от циклических обновлений: изменение источника пересчитывает только остальные модели (в Python — флаг `is_updating`).

### 4.5 Проверка корректности

Результаты работы функций на эталонных цветах:

| Вход RGB | XYZ | LAB (D65) |
|---|---|---|
| (255, 0, 0) | 0.4125, 0.2127, 0.0193 | L=53.24, a=80.09, b=67.20 |
| (0, 255, 0) | 0.3576, 0.7152, 0.1192 | L=87.73, a=−86.18, b=83.18 |
| (0, 0, 255) | 0.1804, 0.0722, 0.9503 | L=32.30, a=79.19, b=−107.86 |
| (255, 255, 255) | 0.9505, 1.0000, 1.0888 | L=100, a=0, b=0 |
| (0, 0, 0) | 0, 0, 0 | L=0, a=0, b=0 |

Значения совпадают со справочными. Пример выхода за охват: LAB(50, 100, −100) → RGB(179, 0, 255) с предупреждением об обрезке.

## 5. Вывод

В ходе работы разработано интерактивное приложение (веб-версия и десктоп-версия на PyQt5) для конвертации цветов между моделями RGB, XYZ и LAB. Все преобразования реализованы вручную по стандартным формулам sRGB и CIE 1976 с опорным белым D65, включая гамма-коррекцию и программное обращение матрицы. Приложение синхронно обновляет все модели при изменении любой компоненты и предупреждает пользователя о выходе цвета за охват sRGB.
